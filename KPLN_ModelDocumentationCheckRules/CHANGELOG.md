# Изменения

## 0.1.2 — 2026-10-26

Проверены и уточнены три слоя: общий → раздел → проект + раздел. Добавлены явно
пустые АР и МТРС/ПАР1–АР; существующие общие допуски не перенесены в локальные слои.
Режим --common-only сохраняет известный контекст и не читает локальные правила.
Добавлены проверки изоляции проектов/разделов и явного переопределения; null и
нетекстовое основание изменения теперь отклоняются.

Закреплена методика поиска 2D-имитации модельного элемента (critical, с отдельной
оценкой уверенности) и нечитаемого наложения таблиц (medium). Уточнены источник и
критичность ручного объёма поверх автоматической спецификации, границы выводов
по одному листу и различие между охватом проверки и допусками. Случаи, ID, PDF и
HTML остаются на C:. Резервная копия установщика скилла также перенесена на C:.
Короткий скилл, DLL моста, модели и прежние отчёты этим выпуском не изменяются.

## 0.1.0 — 2026-10-26

Создан центральный набор проверки документации. Три допуска перенесены на общий
уровень по прямому решению пользователя. Добавлены три уровня наследования,
обязательный сбор аннотаций листов спецификаций, независимая проверка наложений,
разделение подозрения/доказательства, требования к простому HTML и отказ от
автоматического управления рабочим столом. Архивирован разбор МТРС ОВ2.7/ОВ2.9,
включая уточнение по 6675135. DLL моста и модель не менялись этим выпуском.

## 2026-10-26 — хранение результатов
Результаты реальных проверок перенесены на C: пользователя. Добавлен rules/storage.md; обновлены маршрутизация и короткий скилл. Критерии оценки не изменены.

## 2026-10-26 — выделение замечаний
Принят USER-GREEN-FRAMES: зелёные рамки на критичных карточках без дублирования ID. Изменён формат отчёта, критерии оценки не менялись.

## 0.1.1 — 26.10.2026
Подмена измеренного размера — critical для всех разделов. Обычные текстовые размеры без установленной числовой подмены выделены в DOC-MANUAL-DIMENSION. Зелёные рамки обязательны для всех уровней замечаний; USER-GREEN-FRAMES-ALL заменяет прежнее ограничение.
