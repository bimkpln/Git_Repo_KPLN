# Данные моста и границы доказательства

Использовать действующий KPLN_RevitMcpBridge. Сначала list_revit_sessions и
get_revit_context. Запросы текущей задачи — только чтение/экспорт в файл.
Не добавлять новый транспорт или сервер для хранения правил.

Минимум для поиска наложений уже доступен: get_revit_view_annotations / карточка
элемента отдают текст TextNote, OwnerViewId, bounds/location; get_revit_sheet_layout
отдаёт размещение и bounds фрагментов спецификаций. get_revit_sheet_contents
сам по себе в некоторых версиях не содержит координат. Общий bounding_box карточки
может быть null при доступном annotation.bounds — проверять специализированные поля.
Обнаружение числа внутри bounds таблицы возможно без изменений моста.

Не обещать поля по версии: проверить фактический ответ. Для маскирующих областей
может потребоваться отдельная выборка по категории; отсутствие геометрии отражать
как not_checked. Отрицательная проверка по потенциальной видимости не доказывает
видимость каждого элемента в готовой печати.
Для 2D-имитации читать категории детализации/областей и параметры типа отдельно,
если они не вошли в коллекцию аннотаций. Сохранять координаты и единицы, различать
потенциальную видимость и видимость на печати. Пустая выборка модельной категории
в одном виде не является доказательством отсутствия объекта во всём проекте.

Для доказательства конкретной подмены полезная будущая доработка (ещё не выполнена
в этой задаче): координаты ячеек и строк именно размещённого фрагмента, связь
segment → диапазон строк, объединённые ячейки/Header/Body, размеры/поворот, исходное
содержимое, контуры масок. В результате можно сопоставить TextNote с ячейкой
«Количество / позиция …» и исходным значением. Саму доработку выполнять только
как отдельное задание, не считать её уже реализованной.

Известные ошибки экспорта по исходному кейсу: native PDF internal error;
PDFCreator: отсутствует профиль/привязка, не назначается нестандартный формат A2×3.
Это исторические симптомы, а не доказанные текущие настройки или ошибки самих листов.
Различать транспортный сбой, отказ экспорта и нарушение в модели. Сохранять manifest
с листами/ошибками. После таймаута не повторять запись/печать до выяснения статуса.
