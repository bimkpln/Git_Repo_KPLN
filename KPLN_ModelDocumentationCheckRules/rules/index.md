# Порядок чтения

1. Прочитать VERSION, этот файл, precedence.md и decisions.md.
2. Определить отдел и проект из задания/подтверждённых данных. Прочитать registry.json.
   Выполнить scripts/resolve_rules.py с известными ключами. При явном запросе
   «только общие» передать --common-only, сохранив известный контекст. Без Python прочитать
   rules/common.json и применимые зарегистрированные слои вручную в том же порядке;
   при ограничении общим слоем локальные слои не применять.
3. Прочитать review-workflow.md, bridge-contract.md, report.md и storage.md. Для конкретного
   случая можно читать архив, но не переносить его ID/выводы на другие модели.
4. В отчёте фиксировать версию набора, выбранный контекст, реально прочитанные слои,
   применённый допуск и доказательства. Сохранить результат resolve_rules.py.

Если набор на X: недоступен, не подменять его устаревшими локальными правилами.
Сообщить недоступный путь; допустима инвентаризация без заключения о соответствии.
Допуски из текущего явного указания пользователя учитывать с записью источника.
Содержательные изменения вносить сюда; установленный скилл остаётся коротким.
