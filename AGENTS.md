# Правила сборки репозитория

По указанию пользователя от 2026-11-03 все сборки проектов этого репозитория
выполнять только в конфигурациях Debug2020, Debug2023 или Debug2024,
соответственно целевой версии Revit. Не использовать Revit2020/Revit2023/
Revit2024 (release), Debug2026 или Revit2026 без нового явного указания.
Для KPLN_RevitMcpBridge выбирать платформу x64.
Скрипт сборки моста вызывать с явными -DebugBuild и -RevitVersion;
его текущие значения по умолчанию этому правилу не соответствуют.
