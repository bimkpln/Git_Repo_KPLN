# Полное дерево метаданных NWD

`engine/NwdMetadataProbe.cs` — отдельный читатель NWD через установленный
Navisworks SDK. Он не открывает RVT, не сохраняет модель, не выгружает материал
для сравнения и не является полным проверяющим движком. Сборка:

```text
python scripts/build-nwd-metadata.py --runtime "<installed Navisworks runtime>" --output "<new build directory>"
NwdMetadataProbe.exe "<input.nwd>" "<new metadata directory>"
```

Нужны установленный runtime/лицензия Navisworks и .NET Framework compiler.
Существующие `nodes.json`/`manifest.json` не перезаписываются. Вход разрешён
только с расширением NWD; его хеш проверяется до и после чтения.

Узлы записываются потоково с родителем, источником NWC, полными категориями
и внутренними именами свойств, оценённым членством наборов «Скрыть», признаком
видимости и доступными габаритами. Единицы берутся из манифеста моделей.
`nwd_metadata.validate_metadata_export` проверяет количество, иерархию,
происхождение, хеши входа/читателя/данных и покрытие скрытых наборов.
Успех не означает геометрическую приёмку или доказанное назначение проёмов.

Основная выгрузка геометрии schema 2 хранит полное дерево в оболочке
`{"nodes": [...]}`. Для неё `nwd_scene_nodes.scene_nodes` требует ожидаемое
число узлов из манифеста. Обход ключей оболочки вместо самих узлов запрещён.
Отдельный читатель метаданных schema 1 использует потоковый JSON-массив.

`semantic_evidence.declared_role_candidates` ищет только кандидатов назначения
по именам и значениям оговорённых полей экземпляра. Имя параметра, рабочий
набор и случайный текст отделки не доказывают назначение. Совпадение слова
не разрешает исключение БЕП. Категории/внутренние имена свойств сохраняются;
одноимённые поля разных категорий нельзя безусловно сворачивать в словарь.

Дополнительный NWD служит справкой о назначении после проверки соответствия
текущей модели. Источник и ID проверяются вместе; совпадение ID или габаритов
само по себе не подтверждает всю геометрию. Дата и хеш справочного файла
сохраняются. Его материал не подменяет неизменный расчётный NWD.
