# Геометрия, измерение и группировка

Сравнивать объединённый монолит АР и КР в сборе. Разбиение на стены, пилоны,
слои усиления, балки, цилиндры заполнения и плиты само по себе не замечание.
Ни один раздел не эталон. Обе стороны разности имеют равное значение.

Замечание требует реального геометрического доказательства вне допуска.
Не создавать поверхности заполнением дырок меша, растяжением масок, сеткой
габаритов или предположенным ID. Открытый/невалидный меш требует проверки
исходных граней; неопределённая классификация не доказывает отсутствия элемента.
Геометрия рисования происходит из тех же подтверждённых поверхностей/сечений.

Одно локальное физическое несовпадение — одно замечание независимо от XY/Z и
числа исходных элементов. Два конца длинной стены — отдельные несовпадения.
Связность элементов, общий Revit ID или близость центров не основание группировки.
Отверстие рассматривается целиком по фактическому свободному объёму объединения,
включая пустоты, образованные несколькими телами; не только семейства отверстий.

Технические отверстия: сумма абсолютных несовпадений четырёх соответствующих
граней. Дверные/оконные: превышение суммы левой+правой ИЛИ верхней+нижней.
Смещение целого отверстия не обнуляет сумму противоположных граней.
Равенство допуску разрешено. Отсутствие конструкции/отверстия — замечание
независимо от размера, кроме доказанного исключения БЕП или явного правила проекта.
Особый порог отсутствия отверстия (например большая сторона/диаметр <200 мм)
допускается только по отдельному указанию для проекта; по умолчанию его нет.

Низ наклонного марша проверять вертикально по всей нижней поверхности,
а не только нормальным расстоянием и не только там, где обычная разность >15 мм.
При доказанном наличии отделки в АР применяется только соответствующее исключение
толщины; остальные несовпадения лестницы остаются.

Типовые случаи по этажам объединять только при совпадении геометрии отдельно
АР и отдельно КР, характера и размеров дефекта с переносом по высоте. Простого
равенства типа семейства недостаточно. Одна обычная плоская группа, без вложенных
групп; каждый локальный случай имеет координаты и своих дочерних конфликтов.

ПД: сначала измерить на исходных полных телах, затем ограничить геометрию
замечаний объёмами видов. Обрезка тела не должна создавать искусственных отверстий.
Перекрывающиеся виды не дублируют замечания. Не фильтровать только по центру/ID.
Сортировка: числовые оси, буквенные оси, затем уровень снизу вверх; естественный
порядок обозначений осей, а не лексикографическое 1,10,2.
