# ПД

Рабочая область — переданные планы/разрезы с зарегистрированными объёмами.
Полная проверка СГРВН К2С14 была тестом. Не переносить это исключение по умолчанию.
Основной допуск 15 мм; низ наклонного марша по вертикали 20 мм.
Проёмы дверные/оконные — сумма противоположных граней >15 мм.
Технические отверстия — сумма четырёх граней >100 мм.
Приямки: основной допуск 15 мм, внешние габариты имеют отдельное исключение.
Нет конструкции/отверстия — замечание без порога размера, если не доказано исключение.

Исключения: утолщения фундаментных плит, сваи, крышки кровельных шахт,
фундаменты инженерного оборудования. Назначение должно быть доказано;
не игнорировать похожую плиту только по размеру/высоте. Проверку реальных
пустот фундаментного узла не подменять исключением внешнего утолщения.
Условные исключения — [общие условия БЕП](../common/bep-exceptions.md).
Численные значения и машинные ключи — ../profiles.json, профиль PD.
