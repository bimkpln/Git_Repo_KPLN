# Отчёты для KPLN_Clashes_Ribbon

Сохранить нативную структуру HTML Navisworks, порядок строк/столбцов и классы
clashGroupRow, contentRow, childRow, childRowLast по принятому исходному HTML.
Обязательные поля: Изображение, Наименование конфликта (в сообщении старого
парсера встречается «конфлика» — не переименовывать столбец без проверки),
Расположение сетки, Точка конфликта, Идентификатор элемента и Путь для обеих сторон.
Не создавать похожую произвольную HTML-таблицу. Совместимость проверить фактическим
неизменённым парсером, при этом не писать в рабочую SQLite и не менять плагин.

Группа — несколько дочерних конфликтов; шапка повторяет координаты/пару первого.
Один дочерний конфликт — обычный одиночный, без искусственной шапки группы.
Каждая дочь: ровно один ID АР и один ID КР, собственная точка/изображение.
Отсутствующая сторона: «Нет элемента» и комментарий «Нет стены в АР» и т.п.
Для существующего парсера техническое значение -1 допустимо только как
проверенный маркер отсутствия, не реальный ID. Не подставлять ближайший элемент.
Уровень сохранить наряду с сеткой. Сетку показывать по всему фактическому
несовпадению, например «1–4 по А–Б», не по одной метке и не делить названия по /.
Две толстые вертикальные границы: общая часть / АР / КР.

Категории: 01 вертикальные; 02 горизонтальные (включая фундаменты, капители,
балки/пандусы, кроме отверстий); 03 лестницы; 04 отверстия плит;
05 отверстия стен; 06 отверстия балок/колонн/пилонов/капителей/фундаментов;
07 дверные/оконные проёмы. Пустую категорию не заполнять вымышленными замечаниями.
Утверждённый нативный шаблон названий брать из доступного примера компании;
названия категории не определяют физическую группировку.

Одна картинка на локальное замечание: план XY для горизонтального смещения,
разрез для высоты, с ближайшим окружением и понятным масштабом. Совпадающий
монолит серый, АР красный, КР зелёный. Текста и координационных осей нет;
только обозначение направления XY на плане, соответствующие оси на разрезе.
Буквы не лежат на стрелках. Изображение квадратное с безопасными полями,
целиком в рамке; для плагина облегчённая копия, для проверки отдельная крупная.

UTF-8 с BOM; имена файлов картинок и папки ресурсов — ASCII, относительные пути.
Выдавать HTML вместе с ресурсами в ZIP, проверять пути после распаковки.
Разделять слишком большие HTML по целым группам (ориентир 600 строк на файл),
не обрезать группу между файлами. Счётчик основной = группы + одиночные;
дополнительный = дочерние + одиночные. Все номера из общего реестра.
