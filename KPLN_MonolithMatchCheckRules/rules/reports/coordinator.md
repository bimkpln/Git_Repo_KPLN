# Проверочный отчёт

Полный набор подтверждённых замечаний из того же canonical_entries.json,
номера/группировка совпадают с плагином. Показать основной счётчик групп+
одиночных, отдельно метки и при необходимости физические случаи типовых групп.
Даты первого обнаружения, новое/неотработанное/возобновлено, фильтр и поиск.
Вне области перепроверки не представлять как устранённое; история отдельно.

Планы по уровням АР: сначала горизонтальные конструкции и лестницы, затем
вертикальные; повторить на каждом уровне. Консольная плита между уровнями —
отдельный план «<нижний уровень>_Консоли». Вертикальные: снизу уровень,
сверху местный низ вышележащей плиты, определённый по геометрии, не один
глобальный Z для всего этажа. На вертикальном плане плиты не закрашивать.
Включить все замечания, включая перекрытия и лестницы. Лестницы показывать
только с ошибками: весь марш/площадка серым, реальное несовпадение цветом.

Показать оси проекта, номера замечаний, легенду цветов АР/КР/серый.
Линии осей прерывать около самого несовпадения, подписи делать читаемыми.
Высотное замечание подробно рассматривать на отдельном разрезе, план нужен
для ориентации. Не склеивать план и разрез в единственную мелкую картинку.
Типовые случаи должны находиться на планах каждого соответствующего уровня.

Увеличение изображений и полноэкранный план, поиск ID/номеров, переход к случаю.
Фон плана белый неподвижный, не трансформировать его вместе с геометрией.
Открывать в приложении лишь лёгкую стартовую страницу с кнопкой загрузки;
не восстанавливать огромный встроенный SVG автоматически при открытии чата.
Проверять отдельным браузером с ограничением времени, память, переключение
планов, поиск/фильтры, изображения и ошибки JavaScript. Не прятать неразобранное
за вопросительными знаками: диагностика отдельно, окончательный отчёт после разбора.
