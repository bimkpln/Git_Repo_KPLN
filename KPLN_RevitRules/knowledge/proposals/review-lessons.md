# Наблюдения из проверенных задач

## 2026-09-29 — подбор Nevatom KT

Источник: технические данные Nevatom `NT25-008739-01` от 11.09.2025 и
пользовательская проверка универсального одноуровневого семейства. Все 20
подборов KT получили однозначный тип по ID установки либо по системе и
нормализованной марке. Смешение латинских и кириллических символов в марках —
реальный случай, поэтому буквальное сравнение строк недостаточно.

Поля теплообменников вида `A (B)` нельзя сворачивать в одно значение. В этом
шаблоне первое число согласовано с выбранными температурами, второе — со
справочной точкой производителя. Для модели используется первое, оба остаются
в записи доказательств.

Отдельный лист П8 оказался предложением серии SL и не относится к семейству
KT. Совпадение проекта и номера системы само по себе не разрешает перенос между
сериями.

Подробная область применения и таблица параметров закреплены в
`rules/nevantom-kt-family-mapping.md`. Идентификаторы реальной модели и полный
отчёт сравнения остаются в игнорируемой локальной записи.

## 2026-09-30 — связи патрубков водяного нагревателя

Вложенная секция имеет четыре read-only смещения `Вода_Соединител1/2_смещение
X/Y`, управляемые родителем. Численно подтверждено соответствие Y1 притоку,
Y2 обратке; продольные системные формулы добавляют локальный X к началу
первой найденной секции нагревателя. Значения шаблона нельзя считать
подобранными по документу производителя. Последующее чтение разных X1/X2
подтвердило приток/обратку. Пользователь задал правило при отсутствии
координат производителя: X=L/2 для обоих, Y притока=H/2-50 мм,
Y обратки=H/2+50 мм, от низа корпуса. Подробности, область действия и
ограничения: `rules/water-heater-connectors.md`.
