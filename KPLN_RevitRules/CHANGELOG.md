# Изменения

## 1.2.0 — 2026-09-30

Закреплены связи четырёх смещений патрубков вложенного водяного нагревателя
с параметрами установки и системной размерной цепочкой. По явному указанию
пользователя, при отсутствии координат в подборке пара размещается по центру
секции: X=L/2, Y=H/2±50 мм; приток снизу, обратка сверху. Источник такого
размещения отделён от данных производителя. Изменения касаются знаний;
генератор и модель автоматически не изменяются.

## 1.1.0 — 2026-09-29

Добавлен проверенный разбор подборов Nevatom KT и сопоставление с семейством
`550_Универсальная установка_Одноуровневая_(Об)`: точная идентификация типа,
габариты, подключения, паспортные данные, параметры нагревателя, охладителя и
вентилятора. Значения выбранной и справочной точек производителя хранятся
раздельно; серия SL не сопоставляется с семейством KT. Анализ остаётся только
для чтения и не создаёт операции записи в Revit.

## 1.0.0 — 2026-09-29

Отдельное хранилище знаний для Revit: правила работы с документами,
единицами и пакетами параметров, происхождение анализа, тонкий навык Codex.
Инженерные правила и пороги ещё не обучены.
