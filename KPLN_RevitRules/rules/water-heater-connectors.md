# Водяной нагреватель: параметры патрубков и размещение по умолчанию

Уточнено пользователем 30.09.2026 и проверено чтением родителя и вложенного
экземпляра в одной ревизии. Область: исследованная структура
`550_Универсальная установка_Одноуровневая_(Об)` с вложенной секцией
`550_Вл_Универсальная установка_Одноуровневая_Секция_Водяной нагреватель_(Об)`,
Revit 2023. Для иной структуры сначала проверить связи и плоскости отсчёта.

## Сопоставление

| Параметр вложенной секции | Управляющий параметр установки |
|---|---|
| `Вода_Соединител1_смещение X` | `Вода_Патрубок_Приток_Смещение X` |
| `Вода_Соединител2_смещение X` | `Вода_Патрубок_Обратка_Смещение X` |
| `Вода_Соединител1_смещение Y` | `Вода_Патрубок_Приток_Смещение Y` |
| `Вода_Соединител2_смещение Y` | `Вода_Патрубок_Обратка_Смещение Y` |

Имена вложенных параметров содержат `Соединител` без ь. Управляющие параметры
установки являются параметрами типа без формул; вложенные параметры read-only.
Подтверждение: в согласованных снимках X1/X2=50/100 мм, Y1/Y2=265/365 мм
совпали соответственно с притоком/обраткой. Это наблюдение значений и поведения,
не экспорт прямой таблицы ассоциаций API.

Менять исходные параметры установки. Не записывать непосредственно read-only
параметры вложения или формульные системные координаты. Значения каждого
типоразмера независимы; смена высоты не пересчитывает исходные Y автоматически.

## Координаты

X является локальным продольным смещением в секции. Формулы установки
`Вода_Соединитель1_Системное` и `Вода_Соединитель2_Системное` прибавляют X
притока/обратки к началу секции нагревателя. Для секции №4 это начало равно
`Системный_3_Блок_Длина`. Начало не нужно повторно прибавлять к локальным X.
Формулы выбирают первое совпадение типа с `Системный_Вода` среди секций №3–11;
при отсутствии совпадений возвращают 0 мм. На несколько независимых
нагревателей эти две формулы не рассчитаны.

На согласованном пользователем примере Y задаёт высоту от низа корпуса секции
на боковом виде. В отличие от координаты в этой схеме, мировая координата
центра соединителя зависит от размещения секции, уровня/рамы и поворота.
Высоту рамы не прибавлять к параметрам Y повторно: пример с рамой использует
непосредственно 215/315 мм. Точные мировые центры текущим мостом не извлечены.

## Если координат нет в подборке

Пользователь явно разрешил следующее условное размещение. Приоритет имеют
достоверные размеры производителя. Для каждой отсутствующей координаты
использовать правило ниже, сохраняя явно заданные координаты из подбора.

Для длины секции нагревателя L и высоты её корпуса H, всё в мм:

    X притока  = L / 2
    X обратки  = L / 2
    Y притока  = H / 2 - 50
    Y обратки  = H / 2 + 50

Пара центрируется как группа, межосевое расстояние по вертикали 100 мм.
Приток/соединитель 1 ниже, обратка/соединитель 2 выше. L — длина именно
нагревателя, не длина всей установки и не ширина воздушного проёма.
H — высота корпуса секции, без рамы. Размещение выполняется на выбранной
стороне подключения. Пример пользователя: L=350, H=530 → X1=X2=175,
Y1=215, Y2=315 мм. Не распространять это правило на охладитель, фреон,
дренаж или воздушные соединители без отдельного указания.

Помечать источник этих значений как `user_fallback_centered`, а не
`manufacturer`. Если при такой схеме патрубки выходят за корпус или
пересекаются из-за диаметра, не придумывать новое межосевое расстояние:
отметить конфликт и согласовать его. Отсутствующий диаметр этим правилом
не определяется.

## Сторона и проверка результата

Сторону задаёт `Нагреватель_Трубки_Справа`; формула
`Вода_Угол_Системное = if(Нагреватель_Трубки_Справа, 90°, 270°)`.
`ЗО_Справа` — зона обслуживания, не замена переключателю трубок.
Диаметр вложенных труб согласуется с `Вода_Патрубок_Приток/Обратка_Диаметр`.
Унаследованный диаметр нельзя называть подобранным по PDF.

После изменения проверить исходные параметры, значения вложенной секции,
системные продольные размеры, положение геометрических патрубков и внешних
MEP-соединителей. Равенство записанных чисел не доказывает совпадение центров.
Для каждого действия перечитывать документ/ревизию и ID; числовые ID из
конкретного файла не являются глобальными идентификаторами правила.
