# Подбор Nevatom KT и универсальное одноуровневое семейство

## Область действия

Правило проверено 29.09.2026 по техническим данным Nevatom
`NT25-008739-01` от 11.09.2025, подбор `250911903`, и семейству
`550_Универсальная установка_Одноуровневая_(Об)` в Revit 2023. В источнике
сопоставлены 20 установок серии KT с панелями `Zn / Zn`. Серия, шаблон документа
и тип панели входят в область правила; другой шаблон производителя следует
сначала проверить на тех же текстовых якорях.

Предложение для системы П8 относится к серии SL. Его нельзя переносить в типы
семейства KT без отдельного типа и отдельной проверки геометрии.

## Идентификация типа

1. Основной ключ — `ID установки` из подбора и строковый параметр
   `КП_О_Код изделия`. Совпадение должно быть полным и уникальным.
2. Если код в существующем типе пуст, допускается резервный ключ: система из
   подбора + марка производителя. Марку сравнивать после нормализации регистра,
   пробелов и визуально одинаковых латинских/кириллических `K/К`, `T/Т`, `O/О`,
   `P/Р`, `A/А`.
3. Нечёткое совпадение по одному типоразмеру или расходу запрещено. Если оба
   ключа неоднозначны, тип считается несопоставленным.

Префикс `KT/КТ` в начале марки в части существующих типов отсутствует. Для
сравнения его можно отбросить; при заполнении `КП_О_Марка` сохранять написание
из подбора.

## Сопоставление полей

| Поле Nevatom | Параметр семейства | Правило |
|---|---|---|
| Система | `КП_О_Имя Системы` | Строка, например `П26` |
| Марка после заголовка установки | `КП_О_Марка` | Сохранить исходное написание |
| ID установки | `КП_О_Код изделия` | Строка, не ID расчёта |
| Вес | `КП_О_Масса_Текст` | Число килограммов как строка |
| Сторона обслуживания | `ЗО_Справа` | Правая = 1, левая = 0; `ЗО_Слева` вычисляется формулой |
| Длина установки | `Установка_Длина` | Общая длина в мм |
| Общий размер торцевого вида по горизонтали | `Установка_Ширина` | Наружный габарит корпуса в мм |
| Общий размер торцевого вида по вертикали | `Установка_Высота` | Наружный габарит корпуса в мм |
| Размер первой гибкой вставки `ширина-высота` | `Секция_1_Соединитель_Ширина`, `Секция_1_Соединитель_Высота` | мм |
| Размер последней гибкой вставки `ширина-высота` | `Секция_12_Соединитель_Ширина`, `Секция_12_Соединитель_Высота` | мм |
| Производительность приточного воздуха | `КП_И_Расход воздуха` | м³/ч из общей таблицы; сверить с фактическим расходом вентилятора |
| Свободный напор приточного воздуха | `КП_И_Свободный напор воздуха` | Па; сверить с полем вентилятора `Напор свободный` |
| Мощность водяного нагревателя | `КП_И_Тепловая мощность` | Первое значение, кВт |
| Объёмный расход нагревателя | `КП_И_Расход теплоносителя` | Первое значение, м³/ч |
| Суммарные потери давления нагревателя | `КП_И_Потеря давления теплоносителя` | Первое значение, кПа |
| Мощность водяного охладителя | `КП_И_Холодильная мощность` | Первое значение, кВт |
| Объёмный расход охладителя | `КП_И_Расход холодоносителя` | Первое значение, м³/ч |
| Суммарные потери давления охладителя | `КП_И_Потеря давления холодоносителя` | Первое значение, кПа |
| Мощность двигателя вентилятора | `КП_И_Номинальная мощность` | кВт; не `Мощность требуемая` |
| Номинальный ток двигателя | `КП_И_Ток` | А |
| Обороты фактические | `КП_И_Частота вращения двигателя` | об/мин; не рабочая частота преобразователя в Гц |

`КП_И_Ширина подключения`, `КП_И_Высота подключения` и параметры с суффиксом
`_2` являются формульными представлениями размеров соединителей. Источниками
для записи служат параметры секций, а формульные значения только проверяются.

Рабочая частота вентилятора в Гц и диаметры подключения теплообменников
извлекаются и сохраняются в доказательствах, но в проверенном семействе для них
нет однозначных целевых параметров. Их нельзя записывать в параметры оборотов,
напряжения или размеров воздушных соединителей.

## Парные значения теплообменников

В таблицах нагревателя и охладителя значения имеют вид `A (B)`. Для этого
шаблона `A` относится к выбранной расчётной точке установки, а `B` — к
справочной точке производителя. Это подтверждается согласованными парами
температур теплоносителя, мощности, расхода и потерь давления во всех 20
подборах. В параметры семейства переносится `A`; `B` хранится отдельно как
`reference` и не теряется.

## Проверки перед изменением Revit

- Убедиться, что найдена ровно одна установка и один тип семейства.
- Проверить серию KT, тип панели Zn/Zn и наличие всех обязательных разделов.
- Сравнить расход и свободный напор в общей таблице с фактическими данными
  вентилятора. Расхождение блокирует автоматическую запись.
- Для габаритов и соединителей использовать единицы параметров Revit через
  `UnitUtils`/единицы моста. Числа из подбора нельзя передавать как сырые
  внутренние единицы Double.
- Не записывать формульные и read-only параметры.
- Сначала сформировать сравнение и пакет `dry_run`; применение, сохранение и
  синхронизация остаются отдельными действиями по общей политике Revit.

`src/nevantom_selection.py` реализует разбор и сравнение только для чтения. Он
возвращает выбранные и справочные значения отдельно и не создаёт операции
изменения модели.
