# Патрубки охладителя и дренажа: размещение по умолчанию

## Область действия и источник
Явное указание пользователя от 01.10.2026 для исследованного универсального
одноуровневого семейства. Дополняет water-heater-connectors.md.
Применяется при отсутствии координат производителя; явно заданные координаты
из подбора имеют приоритет для соответствующей оси.

Имена и системные формулы сверены с ранее сохранённым снимком семейства.
Это не свежая проверка живого документа или мировой геометрии.
Перед применением перечитать связи, размеры и ID текущего документа.
Префикс Фреон_Патрубок обозначает параметры семейства, а не доказательство
фреонового контура: в исследованном семействе они используются и для водяного
охладителя. Секцию определять по фактическим связям, не только по префиксу.

## Исходные размеры
L — фактическая длина соответствующей секции в семействе; 310 мм в примере —
не константа для всех типов и не общая длина установки.
H — параметр Установка_Высота, без дополнительного прибавления рамы.
D — текущее значение Дренаж_Патрубок_Диаметр данного типоразмера.
Для дренажа использовать длину именно секции, к которой он относится.
Если секций несколько и связь неоднозначна, сначала определить соответствие.
Не назначать и не менять диаметр на основании этого правила.

## Фреон_Патрубок
| Параметр родителя | Значение |
|---|---|
| Фреон_Патрубок_Приток_Смещение X | L * 0.25 |
| Фреон_Патрубок_Обратка_Смещение X | L * 0.25 |
| Фреон_Патрубок_Приток_Смещение Y | H - Фреон_Патрубок_Приток_Диаметр * 1.25 |
| Фреон_Патрубок_Обратка_Смещение Y | Фреон_Патрубок_Обратка_Диаметр * 1.25 |

Y по тому же правилу, что у Вода_Патрубок: приток сверху, обратка снизу,
каждый отступ определяется собственным диаметром патрубка. При L=310 мм, H=300 мм и обоих диаметрах 25 мм: X обоих 77.5 мм,
Y притока 268.75 мм, Y обратки 31.25 мм. При разных диаметрах использовать отдельные значения; диаметр дренажа для них не подходит.
В сохранённом снимке Системный_Фреон_Соединитель1 использует X ОБРАТКИ,
а Системный_Фреон_Соединитель2 — X ПРИТОКА. Не переносить нумерацию
водяного нагревателя на охладитель без проверки.

## Дренаж_Патрубок
| Параметр родителя | Значение |
|---|---|
| Дренаж_Патрубок_Смещение X | L / 2 |
| Дренаж_Патрубок_Смещение Y | Дренаж_Патрубок_Диаметр * 1.25 |

При L=310 мм: X=155 мм. Y рассчитывается из прочитанного диаметра,
не из радиуса. Пример только для проверки арифметики: D=20 мм → Y=25 мм;
это не назначение диаметра 20 мм реальному семейству.

## Применение и контроль
X — локальное смещение от начала своей секции; начало секции не добавлять
повторно. Y отсчитывается от низа корпуса. Раму учитывают системные формулы,
её высоту к исходным параметрам вручную не прибавлять.
Изменять исходные параметры родителя, не системные формулы или read-only
параметры вложений. Правило задаёт алгоритм заполнения; добавление формул
Revit вместо чисел этим указанием не требуется.
При изменении L, H или D пересчитывать зависимые смещения для каждого типа.
Производитель остаётся источником заданных им координат; вычисленные по этому
правилу значения маркировать user_fallback_cooler_quarter_length_diameter_edge либо
user_fallback_drain_center_diameter, а не manufacturer.
Не создавать патрубки отсутствующих секций. При неизвестном/неположительном
L, H или D не подставлять догадки. Выход за корпус или пересечение патрубков
считать конфликтом, не менять коэффициенты самостоятельно.
Для Double соблюдать единицы Revit; все операнды формул должны быть длинами
в одинаковых единицах. Выполнить dry_run, применить в рамках разрешённой задачи,
перечитать исходные и системные значения. Совпадение чисел само по себе
не подтверждает точную мировую геометрию внешних MEP-соединителей.


## Приоритет каталога над условным размещением
Уточнение пользователя от 01.10.2026 обязательно для всех новых правил
Вода_Патрубок, Фреон_Патрубок и Дренаж_Патрубок:
1. Сначала изучить каталог: явные координаты, размеры на чертеже, цепочки
   размеров, оси, отступы от граней и привязки соединителей.
2. Если информации достаточно, вычислить смещение по каталогу и привести его
   к локальной точке отсчёта и направлению оси семейства с учётом единиц.
   Размер от другой грани нельзя просто скопировать как локальное X или Y.
   Начало секции и раму не добавлять дважды.
3. Только для координаты, которую нельзя определить из имеющихся данных,
   применять согласованное размещение по умолчанию. Наличие рассчитанного
   X не мешает применить fallback для отсутствующего Y, и наоборот.
4. Не подменять присутствующие, но противоречивые или нечитаемые данные
   fallback-значением: зафиксировать неоднозначность и уточнить её.
   Не снимать точный размер по масштабу немасштабного эскиза.
5. В доказательствах хранить страницу, исходные размеры и единицы, расчёт
   относительно базы семейства и результат. Явные данные помечать manufacturer,
   расчёт из каталога — manufacturer_derived, условное размещение — соответствующим
   user_fallback. Каталог имеет приоритет над всеми коэффициентами L/2, L/4,
   H - 1.25D и 1.25D.

## Уточнение диаметра и оси
В последнем указании пользователь назвал X, но заменяемые 3/4 высоты и
направления вверх/вниз относятся к Y. Продольные правила X сохраняются.
«Диаметр подключения» означает диаметр конкретного патрубка: для воды общий
Вода_Патрубок_Приток/Обратка_Диаметр, для охлаждения отдельные диаметры
Фреон_Патрубок_Приток_Диаметр и Фреон_Патрубок_Обратка_Диаметр,
для дренажа Дренаж_Патрубок_Диаметр. Использовать диаметр, не радиус.
Приток сверху: Y=H-1.25D притока. Обратка снизу: Y=1.25D обратки.
Для дренажа сохраняется Y=1.25D дренажа.
Если диаметр неизвестен, не угадывать его и не возвращаться к правилу четвертей.
Это условное размещение только при отсутствии данных каталога для данной оси.
## Обязательный перенос диаметров
Применять [connection-diameters.md](connection-diameters.md): общий диаметр
водяного нагревателя, отдельные диаметры охлаждения и диаметр дренажа переносить
из подбора. После изменения диаметра пересчитывать зависимые условные смещения
в том же пакете. Неизвестный диаметр не считать заполненным по каталогу.
