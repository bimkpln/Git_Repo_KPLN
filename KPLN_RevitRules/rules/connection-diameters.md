# Диаметры подключений теплообменников и дренажа

## Обязательное заполнение по подборке
Указание пользователя 01.10.2026 для исследованного универсального семейства.
Если секция присутствует, обязательно извлечь диаметры её подключений и
сопоставить параметрам родителя. Наличие унаследованного ненулевого значения
не означает, что оно соответствует подборке.

| Подключение | Параметр |
|---|---|
| Водяной нагреватель, общий диаметр входа и выхода | Вода_Патрубок_Приток/Обратка_Диаметр |
| Охладитель, патрубок притока | Фреон_Патрубок_Приток_Диаметр |
| Охладитель, патрубок обратки | Фреон_Патрубок_Обратка_Диаметр |
| Дренаж/отвод конденсата | Дренаж_Патрубок_Диаметр |

В рамках данного семейства нагреватель водяной, оба подключения управляются
одним диаметром. Если источник неожиданно задаёт разные диаметры, не выбирать
один произвольно: общий параметр не представляет такой подбор без уточнения.

Охладитель может быть водяным или фреоновым. Префикс Фреон в именах семейства
не ограничивает применение только фреоном. На воде при равных диаметрах
входа/выхода записать одно и то же число в ОБА параметра. При разных диаметрах
сохранить различие. Равенство определяется источником, а не только веществом.

## Сопоставление линий и единицы
Для каждого патрубка сохранять подпись производителя: вход/выход,
жидкостная/газовая линия, стрелки и схему; сопоставлять её с назначением и
связями патрубка семейства. Предположение «газ больше, значит приток»
не является правилом. Больший/меньший диаметр сам по себе не доказывает
направление потока или соответствие притоку/обратке. При неоднозначности
сохранить обе исходные величины и запросить соответствие, не переставлять их.

Различать наружный диаметр, DN/Ду, резьбу и толщину стенки. Запись 25×3.2
не означает диаметр 3.2 и не разрешает самостоятельно заменить 25 на другой DN.
Использовать вид диаметра, который представляет геометрия/соединитель семейства;
для DN и резьб требуется подтверждённое соответствие, не арифметика по названию.
Физические дюймовые размеры переводить в мм (1 in = 25.4 мм), но обозначение
номинальной трубной резьбы не считать автоматически наружным размером в дюймах.
Для Revit Double преобразовать длину в внутренние единицы и проверить обратно.

## Дренаж
Диаметр дренажа/конденсата заполнять отдельно из соответствующего подключения
в каталоге; не копировать его с жидкостного патрубка, не вычислять по мощности.
Если диаметр отсутствует — явно отметить незаполненный по источнику параметр
и запросить данные. Не считать шаблонный диаметр подтверждённым производителем.
Существующее значение можно сохранить с пометкой inherited_unverified,
не заменять его догадкой или нулём.

## Связь диаметров со смещениями
Сначала определить целевые диаметры из источника, затем рассчитать все
смещения, зависящие от НОВЫХ диаметров, согласно water-heater-connectors.md
и cooling-drain-connectors.md. Если координаты есть в каталоге, приоритет
остаётся за расчётом по каталогу; условные отступы не перезаписывают их.
Полный набор диаметров и смещений передавать в одном пакете на типоразмер,
с пересчётом после набора. Порядок Set также учитывать: в проверенном случае
смена Y перед выравниванием X устранила ошибку охладителя при тех же итоговых
значениях. Это наблюдение для данного семейства, не универсальное доказательство
внутреннего механизма Revit. Не сводить патрубки временно в одну точку.
После применения перечитать диаметры, связанные смещения и формулы;
при доступности проверить вложения и внешние MEP-соединители.
Источники, неизвестные данные и результат проверки сохранять в локальном отчёте.
