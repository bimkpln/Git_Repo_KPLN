# KPLN_JobCandidateModelCheckRules

Проверка моделей кандидатов на работу: отдельный слой правил и методики
оценки тестовых Revit-моделей. Использует существующий `KPLN_RevitMcpBridge`.
Новый сервер, порт и DLL не требуются.

- [Карта правил АР и КР](rules/README.md) — общий порядок документов и открытые вопросы.
- [Порядок проверки](rules/review-policy.md) — получение данных, выполнение проверки и отчёт.
- [Контракт критериев](rules/criteria-contract.md) — критерии, статусы и основание оценки.
- Общие процедуры: [веса](rules/error-weight-policy.md), [основное и дополнительное](rules/assignment-scoring.md), [коллизии](rules/collision-policy.md).
- Уточнения заданий: [АР](rules/ar-assignment-clarifications.md), [КР](rules/kr-assignment-clarifications.md).
- Каталоги ошибок: [АР](rules/ar-error-weights.md), [КР](rules/kr-error-weights.md).
- `skills/kpln-job-candidate-model-check/SKILL.md` — лёгкая точка входа.
- `local/` — игнорируемые задания, профили, снимки и отчёты кандидатов.

Текущая версия указана в `VERSION`. Слой содержит методику, согласованные
уточнения, каталоги весов и общий порядок 9+1 для АР и КР. Готового
исполняемого проверяющего движка и формулы промежуточного балла нет.
Критерии берутся из задания/указаний проверяющего; каталоги не создают
требований к каждому заданию. Без критериев доступна инвентаризация модели
без вердикта о соответствии заданию.
Последующие общие критерии и детерминированные реализации принадлежат
этому слою; навыки и транспорт не должны содержать их копии.

Установка: `./scripts/install-skill.ps1`. Установленный навык получает
`rules-root.txt` с путём к этому checkout; необязательное переопределение —
`KPLN_JOB_CANDIDATE_MODEL_CHECK_RULES_ROOT`. Для обнаружения нового навыка
открыть новую задачу. Правила генерации типоразмеров остаются в
`KPLN_RevitRules` и подключаются только как явно выбранный источник критерия
с зафиксированной версией и подходящей областью применения.
