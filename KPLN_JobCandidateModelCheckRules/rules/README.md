# Структура правил проверки — АР и КР

Редакция: 2026-10-23. Слой правил: 0.1.17.
Порядок работы одинаков для обоих отделов. Общие процедуры хранятся один раз;
предметные требования и исключения — в профиле соответствующего отдела.

## Общие правила

| Порядок | Документ | Содержание |
|---|---|---|
| 1 | [Порядок проверки](review-policy.md) | Источники, чтение модели, доказательства, официальный отчёт |
| 2 | [Контракт критериев](criteria-contract.md) | Профиль, статусы, полнота и основание оценки |
| 3 | [Категории и применение весов](error-weight-policy.md) | Единая шкала, рабочие наборы, двойной учёт, новые типы |
| 4 | [Основное и дополнительное](assignment-scoring.md) | Общие 9+1, отсутствие штрафа за невыполненное дополнительное, экспертная оценка |
| 5 | [Коллизии](collision-policy.md) | API-проверка всей модели, полнота, исходные пары и отчёт |
| 6 | [Оценка и обучение](score-training-policy.md) | Представление балла до десятых и согласованные диапазоны обучения |
| 7 | [Локальные ошибки маркировки](local-marking-errors.md) | Область локального типа с весом 30, одна причина в марке и спецификации |
| 8 | [Неполный состав элементов](missing-model-elements.md) | Частично отсутствующие экземпляры с весом 70, граница со специальными типами |

Для новых проверок АР использовать [реестр действующего задания](ar-current-assignment.json): проверить SHA256 и прочитать сохранённый PDF, не подставляя исходник старого эталона.

Скрытие обязательной категории на выданном плане/виде — критический случай AR-W02-CAT / KR-W07-CAT, диапазон 90–100 по решению пользователя от 23.10.2026. Применимость и защита от двойного учёта — в каталогах отделов.

Отсутствие предусмотренных заданием размеров на существующем узле — критическая категория AR-W10 / KR-W13, диапазон 90–100 по решению пользователя от 23.10.2026. Применимость определяется заданием своего отдела.

## Документы отделов

| Назначение | АР | КР |
|---|---|---|
| Требования, применимость и исключения | [Уточнения АР](ar-assignment-clarifications.md) | [Уточнения КР](kr-assignment-clarifications.md) |
| Известные типы, категории и веса | [Каталог АР](ar-error-weights.md) | [Каталог КР](kr-error-weights.md) |

Оба профиля имеют одинаковый порядок разделов: источник и область;
модельные элементы; рабочие наборы; виды/листы/спецификации/маркировка;
коллизии; основное и дополнительное; неуточнённые случаи.

Оба каталога имеют одинаковый порядок разделов: источник и область;
категории; известные типы; рабочие наборы; применение и двойной учёт;
новые типы; история. Строки расположены по одному смысловому порядку.
ID сохраняются независимо от позиции: перенумерация сломала бы ссылки
исторических отчётов. Неприменимый тип не превращается в новую ошибку
другого объекта; его прежний вес не является действующим штрафом.

## Как вносить изменения

Общее правило менять в общем документе и проверять ссылки из обоих отделов.
Таблица категорий дополнительно показана в обоих каталогах для удобства;
при изменении общей шкалы обновлять обе копии одновременно.
Требование моделировать конкретные элементы не создавать из аналогии
каталогов. При новой версии ТЗ подтвердить область, источник и применимость.

Сохранять версию профиля отдела и всех применённых общих правил в проверке.
Новые решения выпускать новой версией слоя. Исторические задания, профили,
оценки, доказательства и PDF не переписывать.

## Открытые вопросы

| Вопрос | Где зафиксирован | Действие до уточнения |
|---|---|---|
| Применимость полов, крыши, групп и размеров стен на узле КР | [Профиль КР](kr-assignment-clarifications.md) | Уточнить у пользователя; не создавать замен по аналогии |
| Частичное выполнение дополнительного и промежуточная формула балла | [Общая оценка](assignment-scoring.md) | Не вычислять произвольный бонус; экспертная оценка только по запросу |
| Отсутствует один из двух РН либо ТЗ требует другое число РН | [Общие веса](error-weight-policy.md) | `severity_pending`, `weight=null`, остальные проверки продолжать |
| Витражные пары в смешанном результате АР | [Профиль АР](ar-assignment-clarifications.md) | Не распространять исключение без уточнения |
| Допустимые конструктивные пересечения КР и их допуски | [Профиль КР](kr-assignment-clarifications.md) | Разбирать по данным и согласованному основанию; неоднозначность — `needs_review` |
| Вид обучения при ровно 5,0 | [Оценка и обучение](score-training-policy.md) | Указать необходимость согласования объёма обучения |

Общий порядок 9+1 для АР и КР подтверждён пользователем 2026-10-16;
он больше не является открытым вопросом.
