# KPLN_Publication

## Сборка

Откройте `KPLN_Publication.sln` в Visual Studio:

- Revit 2020/2023/2024: `Debug2020/2023/2024` или `Revit2020/2023/2024`, платформа `x64`, .NET Framework 4.8.
- Revit 2026: `Debug2026` или `Revit2026`, платформа `x64`, .NET 8. Общие настройки подключаются из `..\build\KPLN.Revit2026.props`, как в BIMTools.

Нужны Revit API соответствующего года, KPLN_Loader, KPLN_Library_Forms и KPLN_Library_DBWorker. Для 2026 Debug-сборки используют библиотеки из `bin\Debug\2026`, release — из `bin\2026`. Путь Loader 2026 можно переопределить через свойство `KPLNLoaderPath`.

Обычный Build/Rebuild автоматически восстанавливает отсутствующий `project.assets.json` для 2026, в том числе при Batch Build из Visual Studio.

Debug DLL создаётся в `KPLN_Publication\bin\Debug\2026`. Конфигурация `Revit2026` сохраняет принятый путь выпуска: `Z:\Отдел BIM\03_Скрипты\09_Модули_KPLN_Loader_v.2\Publication\2026`.

Рядом с DLL необходимы `formats.txt`, `itextsharp.dll` и `BouncyCastle.Cryptography.dll`; сборка копирует их автоматически. Для 2026 используется вариант BouncyCastle `net6.0`; iTextSharp остаётся версии 5.5.13.4.

## Проверка PDF на .NET 8

Из папки решения:

```powershell
dotnet run --project tests\Revit2026Smoke\Revit2026Smoke.csproj --configuration Release
```

Проверка создаёт тестовый PDF с вектором и изображением, выполняет преобразование цветов, обработку границ, объединение PDF и проверяет журналирование. Файлы остаются в папке вывода теста. Запуск Revit и реальная печать через PDFCreator в этот тест не входят.

## Выступающие элементы при пакетной печати

Перед отправкой очередного листа на принтер проверяются габариты видимых элементов относительно основной надписи с допуском 1 мм. Учитываются PDF/изображения, текст, линии, спецификации, видовые экраны и их подписи. Для размещённых видов проверяются габариты видового экрана; скрытые элементы/категории и временно скрытые элементы листа исключаются. Листы с несколькими основными надписями (существующий режим печати по частям) и отдельные виды не проверяются.

При выходе за рамку окно предлагает распечатать этот лист и продолжить либо остановить весь пакет и открыть лист. Закрытие окна также означает остановку. При остановке проблемный лист и оставшиеся листы не печатаются, последующая выдача DWG не начинается. Уже отправленные PDF дожидаются окончания записи и проходят выбранную постобработку, включая объединение. Исходники удаляются только после успешного объединения всего набора. Остановка на первом листе не создаёт пустой объединённый PDF. Итоговое окно показывает результат и папку выдачи; после исправления новый запуск создаёт другую папку, и части комплекта нужно объединить вручную.

Проверка относится к интерактивной команде пакетной выдачи. Режим печати через мост без окон не показывает этот диалог. Ориентация, масштаб и размещение при печати остаются прежними.

Автономные регрессионные проверки (координаты листов насосной/алгоритма, готовность PDF, порядок страниц, сохранение исходников при ошибке объединения):

```powershell
MSBuild.exe tests\SheetBoundary\SheetBoundary.Tests.csproj /t:Build /p:Configuration=Debug /p:BuildProjectReferences=false
tests\SheetBoundary\bin\Debug\SheetBoundary.Tests.exe
```

Проверка в Revit после загрузки новой DLL:

1. Лист в пределах рамки печатается без предупреждения. Видимая PDF-вставка, текст, спецификация или подпись видового экрана за рамкой вызывают предупреждение; скрытие элемента или его категории снимает предупреждение.
2. «Распечатать» продолжает текущий пакет. На следующем проблемном листе решение запрашивается отдельно. Многосоставной лист печатается по прежней схеме без этого предупреждения.
3. Для набора «обычный — проблемный — обычный» остановка выдаёт только первый лист. Проверить варианты с объединением и без него, а также остановку на первом листе и закрытие окна крестиком.
4. При совместной выдаче PDF+DWG остановка не запускает DWG. Итоговое окно показывает фактическую папку; открывается проблемный лист с выделенными элементами. Для листа из связи проверить возврат связи после печати и открытие нужного документа.

### Выбор для всего пакета и отчёт

Предупреждение содержит три кнопки: «Распечатать», «Распечатать для всех», «Остановить печать». Второй вариант действует только до конца текущего запуска: проверки продолжаются, но новые предупреждения не открываются. Окно статуса скрывается на время выбора и возвращается при продолжении.

Все проблемные листы, отправленные на принтер, перечисляются в итоговом окне (модель, номер/имя листа, количество и список элементов). Список сохраняется рядом с PDF в файле «Проверить_листы.txt», в том числе при последующей остановке или ошибке пакета. Неотправленный лист остановки указан отдельно в сообщении об остановке.
