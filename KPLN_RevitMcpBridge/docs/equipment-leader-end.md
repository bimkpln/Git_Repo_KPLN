# Свободный конец марки оборудования — 1.1.9

update_tags принимает leader_end_mm для одной локальной цели категории
OST_MechanicalEquipment (FamilyInstance), кроме ранее поддержанных труб.
Точка должна лежать внутри преобразованного габарита своего оборудования
с допуском 2 мм по каждой координате. Это только проверка области:
попадание на видимый контур подтверждается отдельно по виду/PDF.
Для труб сохранена проверка попадания на конечную ось с допуском 2 мм.
Связи и остальные категории не поддержаны. После записи конец остаётся Free.

get_view_annotations возвращает leader_geometry: condition, end_mm и elbow_mm
для доступных выносок. У Attached конец null, поскольку API не разрешает его
чтение; отсутствие доступных данных не означает нулевые координаты.

Сборки проверены для Revit 2020/2023/2024/2026. 36 существующих тестов проходят.
Запись конца оборудования в живом Revit ещё не проверена: требуется полный
перезапуск Revit для загрузки DLL 1.1.9. Перед массовой правкой обязательны
dry_run одной марки, чтение фактического конца и проверка PDF.
