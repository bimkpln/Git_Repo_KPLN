# Диапазон плана и соединения MEP — 1.1.8

`get_revit_plan_range` читает четыре плоскости плана, реальные уровни и смещения в мм.
`copy_revit_plan_range` переносит диапазон с существующего плана того же уровня.
`set_revit_plan_range` задаёт диапазон напрямую, без вида-источника. Обязательные
`top_offset_mm`, `cut_offset_mm`, `bottom_offset_mm`, `depth_offset_mm` — конечные
числа в мм от связанного уровня целевого плана. Все четыре плоскости привязываются
к этому уровню. Например, для ТРЦ +16.550: 4650, 1200, -150, -150 мм.
Допустимость проверяется через `CheckPlanViewRangeValidity`; недопустимый диапазон
отменяет весь пакет. Шаблоны видов и общие параметры шаблона не изменяются.
Обязательны document_id и expected_revision; по умолчанию Commit и откат.
После пробы обновить revision. Шаблон не меняется; если он контролирует диапазон,
операция отклоняется. Результат перечитывается до завершения транзакции.

`get_revit_mep_connections` читает до 100 элементов и физические соединители с
реальными соседями. Для арматуры/фитингов возвращается PartType, в том числе Tee.
Координаты — внутренние мм. Направление потока и начало ветви этим не определяются.

Для загрузки версии нужен полный перезапуск Revit и MCP-сервера.
Компиляция и тесты транспортного контракта не заменяют dry_run на живой модели.
