# Размещение на листе — мост 1.1.10

`move_revit_sheet_items` перемещает уже размещённые `Viewport` и
`ScheduleSheetInstance`, сохраняя их ID и настройки. Для каждого экземпляра
передаются `sheet_unique_id`, `instance_unique_id`, `expected_point_mm` и
`point_mm`. Это миллиметры листа, Z=0. Ожидаемую позицию брать из нового поля
`placement_point_mm` команды `get_revit_sheet_layout`: служебная Z у
`center_mm` видового экрана не является координатой вставки.

Проверяются документ/revision, принадлежность листу, прежняя позиция с
допуском 0,1 мм, закрепление, группа, тип элемента и результат перемещения.
Ведомости изменений внутри основной надписи защищены. Повторы одного
экземпляра в пакете отклоняются. До 100 записей, единая транзакционная группа.
`dry_run=true` выполняет Commit и откат; затем надо обновить revision.
RVT не сохраняется и не синхронизируется.

После Commit `place_revit_views` и `move_revit_sheet_items` автоматически
проверяют все окна и самостоятельные спецификации на затронутых листах.
Пересечение габаритов, выход за бумагу или неизвестная геометрия дают
`sheet_layout_conflict` и откат **всего пакета**, включая уже завершённую
внутреннюю транзакцию. Промежуточные положения отдельных перемещений не
проверяются — можно переставить несколько объектов за один пакет.
Существующие конфликты того же листа также нужно устранить этим пакетом.

`check_revit_sheet_layout` — отдельное чтение результата после любых правок,
включая новые марки, изменение масштаба, диапазона или формата:

- Габарит окна берётся из `GetBoxOutline`, а не `CropBox`: аннотации за
  подрезкой входят в проверку. Заголовок `GetLabelOutline` проверяется отдельно.
- Габарит каждого экземпляра/сегмента спецификации читается на его листе;
  преобразуются все восемь углов `BoundingBoxXYZ`.
- `minimum_gap_mm` задаёт нужный зазор, по умолчанию 0. Это настройка задачи,
  а не приписанный нормативу минимум.
- `content_min_mm` и `content_max_mm` задают измеренное полезное поле внутри
  рамки. `reserved_regions` исключают штамп и служебные зоны. Без этих данных
  проверяются только края бумаги: ответ явно содержит `frame_supplied=false`.
- Ошибки/нулевые габариты не считаются отсутствием пересечений:
  `complete=false`, `bounds_clear=false` и список `unreadable`.
- Габариты консервативны и могут включать пустоту. Проверка не утверждает,
  что она распознала пиксельные пересечения. Финальный PDF обязателен.

Если композиция не помещается внутри рамки, сначала пересчитать размещение,
затем увеличить **допустимый** формат основной надписи через существующий
`set_revit_parameters` по прочитанным параметрам экземпляра 020_. Сохранять
оговорённый масштаб и читаемость. После смены формата заново измерить границы,
штамп и композицию; произвольные форматные значения не подставлять.

Для загрузки DLL 1.1.10 необходим полный перезапуск Revit после сохранения
пользователем нужных изменений. Перезапуск HTTP-моста DLL не обновляет.
MCP-процесс также должен перечитать Python-сервер с двумя новыми командами.
